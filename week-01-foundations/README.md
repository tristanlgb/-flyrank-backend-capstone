# Week 1 — Node and HTTP Foundations

> The exact Week 1 assignment was not supplied. This is a transparent
> foundations exercise that establishes the runtime, Express app structure,
> JSON request parsing, status codes, testing, and a health endpoint needed by
> the later weeks.

```bash
npm install
npm start -w week-01-foundations
```

- `GET /` describes the API.
- `GET /health` proves the service is alive.
- `POST /echo` returns the submitted JSON and demonstrates request → handler → response.

Run `npm test -w week-01-foundations` to verify the flow.
